# API REST de Series

Práctica Obligatoria - Desarrollo de APIs con Spring Boot.

## Tecnologías
* Java
* Spring Boot
* Spring Data JPA
* Base de datos H2
* Lombok

## Endpoints
* GET /api/series
* GET /api/series/{id}
* POST /api/series
* PUT /api/series/{id}
* DELETE /api/series/{id}

## Ejecución
1. Clonar el repositorio.
2. Abrir en IntelliJ IDEA.
3. Ejecutar la clase `ApiSeriesApplication`.
4. El servidor correrá en `http://localhost:8080`.
